Работа с БД и логами

Клиент-серверное и Web-тестирование

· Использовал Charles для подмены ответов сервера и проверки обработки ошибок на клиенте.
· Проверял вёрстку и стили по макетам в Figma.
· Проводил кроссбраузерное и кросс-платформенное тестирование через BrowserStack.
