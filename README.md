КЛЮЧЕВЫЕ КОМПЕТЕНЦИИ:

· Области: Микросервисная архитектура (сервисы оплаты, авторизации, ачивок, PvP), Монолит, Клиент-сервер, Базы данных.

· Инструменты: Devtools, Postman (коллекции, окружения), Swagger, SoapUI, WireMock, Kafka, Jaeger, Kibana, Sentry, Grafana, Git, GitLab CI/CD, Charles Proxy, BrowserStack.

---

ПРОФЕССИОНАЛЬНЫЙ ОПЫТ:

Участие в разработке высоконагруженной микросервисной платформы с доменами: оплата, пользователи (авторизация), геймификация (ачивки, аватары) и PvP-взаимодействие.

ОБЯЗАННОСТИ:

API И ИНТЕГРАЦИОННОЕ ТЕСТИРОВАНИЕ МИКРОСЕРВИСОВ:

· Проводил ручное и интеграционное тестирование распределенной системы (REST/SOAP API), проверяя корректность взаимодействия между сервисами оплаты, авторизации и ачивок.

· Проектировал и поддерживал коллекции в Postman, используя переменные окружений и скрипты для автоматизации проверок статус-кодов и схем ответов (JSON Schema).

· Тестировал асинхронное взаимодействие через Kafka: проверял доставку событий (например, после успешной оплаты отправляется событие в сервис ачивок) и обрабатывал сценарии с задержками.

· Использовал WireMock для создания заглушек зависимых сервисов, что позволяло тестировать пограничные состояния (таймауты, ошибки 5xx) и изолировать тестируемый компонент.

· Применял Jaeger для трассировки запросов при поиске проблем в микросервисной цепочке (например, при сбоях в PvP-битвах).

РАБОТА С БД И ЛОГАМИ:

· Выполнял прямую валидацию данных в PostgreSQL (использование JOIN, GROUP BY, агрегатных функций) и MongoDB для проверки консистентности данных после сложных транзакций (покупка аватаров, завершение битв).

· Интегрировал анализ систем логов в ежедневную практику: работа с Kibana для поиска ошибок по трейс-идам, Sentry для отслеживания эксепшенов на клиенте, Grafana для мониторинга метрик сервисов.

ФУНКЦИОНАЛЬНОЕ И КЛИЕНТ-СЕРВЕРНОЕ ТЕСТИРОВАНИЕ:

· Проводил сквозное (E2E) тестирование пользовательских путей: от UI (фронтенд) до проверки записи в БД.

· Использовал Chrome DevTools (Network, Application, Cookie, Local Storage) и Charles Proxy (подмена ответов, тестирование офлайн-режимов) для проверки обработки ошибок на клиенте и безопасности хранения данных.

· Участвовал в регрессионном тестировании фронтенда, проверяя вёрстку по макетам Figma и кросс-браузерную совместимость (BrowserStack).

ДОКУМЕНТИРОВАНИЕ И УЧАСТИЕ В ПРОЦЕССАХ:

· Разрабатывал и актуализировал тест-кейсы и тест-сьюты в Test IT для обеспечения полного регрессионного покрытия ключевых модулей.

· Составлял декомпозицию функционала в виде MindMap (Miro) для визуализации зон покрытия тестами.

· Оформлял баг-репорты в Яндекс.Трекер с высоким уровнем детализации (шаги, фактические и ожидаемые результаты, приложенные логи и скриншоты).

· Участвовал в ревью требований (аналитика), выявляя противоречия в логике на ранних этапах.

· Работал с Git (ветвление), участвовал в CI/CD пайплайнов в GitLab (сборка стендов).
