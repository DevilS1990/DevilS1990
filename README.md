## Привет！ 👋
Меня зовут Михаил, я QA Engineer

Продуктовый стартап, команда 6 человек. Участвовал в тестировании микросервисной архитектуры, включая сервисы оплаты, авторизации, ачивок и покупки аватаров.

Что делал и какие результаты:

✅ Тестирование API и микросервисов

Проводил ручное тестирование REST/SOAP API (Postman, Swagger, SoapUI)

Настроил коллекции в Postman с переменными окружений для быстрого переключения между стендами

Использовал WireMock для создания заглушек при тестировании фронта

Проверял асинхронные сценарии через Kafka и трассировку в Jaeger

✅ Работа с базами данных и логами

Писал SQL-запросы средней сложности (join, group by, агрегатные функции) в PostgreSQL, MongoDB

Анализировал логи в Kibana, Sentry, Grafana для поиска причин ошибок

Проверял работу кэша в Redis

✅ Клиент-серверное и Web-тестирование

Тестировал фронт с помощью Devtools (Network, Application, Cookie, Local Storage, Cache)

Использовал Charles для подмены ответов сервера и проверки обработки ошибок на клиенте

Работал с Figma для проверки вёрстки и стилей

✅ Документирование и процессы

Создавал тест-кейсы и тест-сьюты в Test IT для регрессионного тестирования

Оформлял баг-репорты в Яндекс.Трекер

Составлял чек-листы в Miro (MindMap) — [https://miro.com/app/board/uXjVGIHpuDY=/?share_link_id=207625199249]

Участвовал в тестировании требований к фичам

✅ Интеграция и DevOps-практики

Работал с Git, создавал репозитории, настраивал CI/CD в GitLab (сборка в PROD/STAGE)

Использовал Linux (базовые команды, tail -f для логов в реальном времени)

Анализировал метрики в Яндекс.Метрике для определения популярных браузеров и устройств

✅ Автоматизация и эффективность

Писал простые автотесты на JavaScript

Активно использую GPT и нейросети для ускорения рутинных задач


Ключевые навыки:

Категория: Технологии
Тестирование: API REST, SOAP, Postman, Swagger, SoapUI, WireMock

Web: Devtools, Charles, HTTP/HTTPS, Cookie, Local Storage, Cache

Базы данных: SQL (PostgreSQL), MongoDB, Redis, DBeaver, Compass

Логи и мониторинг: Kibana, Sentry, Grafana, Jaeger

Брокеры сообщений: Kafka

Документирование: Test IT, Яндекс.Трекер, Jira, Confluence, Miro, Figma

CI/CD и контроль версий: Git, GitLab CI/CD, GitHub

ОС и окружение: Linux (базовые команды), Bash

Аналитика: Яндекс.Метрика, Metabase

Дополнительно: JavaScript (базовый), Agile, GameDev, кроссбраузерное тестирование, регресс
